# Specification: AI-TLP phpDocumentor Extension

## 1. Introduction
This extension for phpDocumentor (phpDoc) aims to provide a standardized way to document the level of AI involvement in PHP codebases, following the **AI Traffic Light Protocol (AI-TLP)** as defined by [NLKW](https://nlkw.de/en/blog/ai-tlp/).

The goal is to allow developers to declare the "epistemic status" of their code, indicating how much human judgment and review was applied to AI-generated content.

## 2. Proposed PHPDoc Tag
The extension will introduce a new tag: `@ai-tlp`.

### Syntax
`@ai-tlp <level> [<description>]`

- **`<level>`**: The AI-TLP level. Supported formats:
    - Short form (recommended): `white`, `green`, `amber`, `orange`, `red`, `yolo`.
    - Full form: `AI:WHITE`, `AI:GREEN`, etc. (case-insensitive).
- **`<description>`**: (Optional) Additional context, e.g., which tools were used or which parts were specifically reviewed.

### Supported Levels
| Label | Keywords | Meaning |
| :--- | :--- | :--- |
| `AI:WHITE` | `white` | Written independently, no significant AI involvement. |
| `AI:GREEN` | `green` | AI-assisted. Author drove the process, AI used as a tool. |
| `AI:AMBER` | `amber` | AI-generated, fully reviewed line by line. Author can explain every part. |
| `AI:ORANGE`| `orange`| AI-generated at scale. Architecture understood, hot spots reviewed, but not every line. |
| `AI:RED`   | `red`   | AI-generated, only checked for plausibility. Draft quality. |
| `AI:YOLO`  | `yolo`  | AI-generated, unreviewed. |

## 3. Architecture
The extension will consist of the following components:

### A. Tag Definition
Custom tag handler for `@ai-tlp` that parses the level and optional description.

### B. Validation
- Ensures the level is valid (one of the 6 defined above).
- (Optional) Integration with static analysis tools (e.g., PHPStan) to enforce project-wide AI usage policies (e.g., "No AI:RED in production").

### C. Rendering / Templates
- Integration with phpDocumentor's Twig templates.
- Visual representation using color-coded badges or icons corresponding to the traffic light colors.
- Accessible text fallbacks.

## 6. Implementation Roadmap
1. **Basic Tag Support:** Implemented for phpDocumentor 3.10.
2. **Template Integration:** A copyable override for the default HTML template is provided.
3. **Policy Configuration:** Project-wide minimum levels remain a proposal.

## 7. Testing Strategy
A robust testing suite is essential to ensure compatibility with various phpDocumentor versions and accurate parsing of the custom tag.

### A. Unit Tests
- **Tag Parsing**: Verify that `AiTlpFactory` correctly identifies the `@ai-tlp` tag and extracts both the level and the description.
- **Level Validation**: Test the `AiTlpValidator` with valid keywords (`white`, `amber`, etc.), full labels (`AI:GREEN`), and invalid input (ensuring helpful error messages).
- **Case Sensitivity**: Confirm that levels are correctly parsed regardless of casing (e.g., `AMBER` vs `amber`).

### B. Integration Tests
- **End-to-end**: Install the package in a temporary Composer project and run the
  phpDocumentor 3.10 PHAR to check discovery, parsing, rendering, error reports,
  and cached builds. Set `PHPDOC_PHAR` to the PHAR path to run this test locally.

### C. Compatibility Tests
- **PHP Versions**: Run the test suite against supported PHP versions (8.1, 8.2, 8.3).
- **phpDocumentor Versions**: The integration test currently targets 3.10.0.

### D. Manual Verification
- The `examples/` directory contains sample configuration and source files.
  Follow the README to install the extension and template override in a project.

### E. Continuous Integration (CI)
- **GitHub Actions**: A workflow will be implemented to automatically run the entire test suite on every push and pull request.
- **Static Analysis**: Integration of PHPStan and PHP_CodeSniffer into the CI pipeline to maintain high code quality and PSR-12 compliance.
- **Automated Matrix**: The CI will test across a matrix of PHP versions (8.1, 8.2, 8.3, 8.4) to guarantee broad compatibility.

## 8. Technical Requirements
- PHP 8.1+
- phpDocumentor 3.10 (3.10.0 PHAR tested)
- Composer for dependency management
- The extension's development dependencies include phpDocumentor and a
  `league/flysystem` alias; consuming projects should use the phpDocumentor
  PHAR as described in the README.
